# Diabetes Risk Prediction Using Machine Learning

🚀 Live Demo

Try the application here: [Diabetes Risk Prediction Web App](https://diabetes-risk-prediction-vdj7bjrwxip624zxzpruja.streamlit.app/)

## Overview
This project explores diabetes-related classification using machine learning and provides an interactive Streamlit application for instant predictions.

## Objectives
- Explore and preprocess a public diabetes dataset.
- Train and compare Logistic Regression and Random Forest classifiers.
- Evaluate model performance using precision, recall, F1-score, ROC-AUC and a confusion matrix.
- Provide a real-time web interface for model inference.

## Technologies
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Streamlit
- Joblib

## Project Structure
- `Diabetes_Risk_Prediction.ipynb` — data analysis and model training
- `app.py` — Streamlit prediction application
- `models/` — saved model and feature names
- `requirements.txt` — Python dependencies

## How to Run Locally
1. Install the dependencies: `pip install -r requirements.txt`
2. Ensure the saved model files are in the `models/` folder.
3. Run: `streamlit run app.py`
4. Open the local URL displayed in the terminal.
